# EduPulse-AI
EduPulse AI is an AI-powered smart campus platform using microservices architecture. It tracks student academics, skills, GitHub, coding progress, assessments, and placements with AI agents, analytics, personalized tasks, smart notifications, and real-time insights for students, faculty, parents, and management.

AI-powered smart campus intelligence platform using microservices architecture.

## Architecture

- Spring Boot Microservices
- Spring Cloud Gateway
- Eureka Service Discovery
- Kafka Event Streaming
- RabbitMQ Message Queue
- PostgreSQL
- Redis
- AI Agents
